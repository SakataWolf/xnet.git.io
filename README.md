# xnet.git.io
📱 Calculadora Proporcional de Planos (PWA)  Uma Progressive Web App (PWA) desenvolvida para realizar o cálculo proporcional de planos mensais de forma rápida, precisa e intuitiva. Ideal para provedores, empresas de serviços recorrentes ou equipes comerciais que precisam calcular valores proporcionais entre datas de instalação e vencimento.
